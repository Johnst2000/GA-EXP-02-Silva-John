## Contenido
- `main.tex`: informe (una sección por equipo observado).
- `main.pdf`: PDF compilado.
- `hojas_campo/`: hoja de campo de cada equipo observado, en archivos de bloc de notas (.txt) tomados durante la sesión, sin modificar. Por indicación del docente en clase, las hojas se llevaron en bloc de notas y no a mano.
- `nota.py`: comprueba la nota sugerida (opcional).

## Compilación
- Compilador: pdflatex (TeX Live o MiKTeX).
- Archivo principal: `main.tex`.
- Dependencias: paquetes estándar (geometry, booktabs, array, url, hyperref, enumitem).
- Comandos (ejecutar dos veces):

```
pdflatex main.tex
pdflatex main.tex
```
